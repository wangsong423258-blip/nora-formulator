# Changelog

## v1.1.1-preview

- Publish SDK 0.3.1 and release status metadata for the Nora 1.1.1 distribution plan.
- Document macOS ARM64 and Windows x64 Local and Self-hosted deployment modes.
- State Community attribution and the separate Commercial / Enterprise authorization policy.
- Preserve Canonical API v1 and the existing SDK implementation.
- Retain the macOS native reference result of 160/160 exact; no final installer acceptance is claimed.
- Withhold all four Runtime packages: usable macOS distribution provisioning is incomplete and no runnable Windows PE Runtime is available.
- Windows native validation, Apple notarization and Windows signing remain pending.

## SDK 0.3.1

- macOS Apple Silicon target and authenticated local uninstallation.
- Signed offline bundle verification and Runtime lifecycle integration.

## SDK 0.3.0

- Signed distribution format v2, compatibility checks, device enrollment and license grant import.
- Transactional update and recovery commands; Canonical API v1 unchanged.

## SDK 0.2.0

- Local HTTP SDK transport and Runtime status types.
- English and Chinese attribution components.

## SDK 0.1.0

- Initial developer interface, 96 Canonical v1 operations, schemas and examples.
